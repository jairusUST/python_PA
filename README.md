# EXPERIMENT 1: INTRODUCTION TO PYTHON PROGRAMMING

This repository contains Python solutions for introductory programming problems covering string operations, functions, and list unpacking.

## Contents

A. Word Rotation Problem – Rotates a string by moving the first character to the end using string slicing.

B. Username Builder Problem – Generates a formatted username (first.last) by lowercasing names and stripping spaces.

C. Bookend Swap Problem – Swaps the first and last elements of a list using extended sequence unpacking (*middle).
